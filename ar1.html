Processus Autorégressif d'Ordre 1

Analyse détaillée des propriétés statistiques d'un AR(1)

Un processus AR(1) est défini par l'équation : \[X_t = \phi X_{t-1} + \varepsilon_t\] où \(\varepsilon_t \sim \text{WN}(0, \sigma^2_{\varepsilon})\) est un bruit blanc de moyenne nulle et de variance \(\sigma^2_{\varepsilon}\).

Calcul de la Moyenne

Prenons l'espérance de \(X_t\) :

\[E[X_t] = E[\phi X_{t-1} + \varepsilon_t] = \phi E[X_{t-1}] + E[\varepsilon_t]\]

Comme \(E[\varepsilon_t] = 0\) et en supposant que le processus est stationnaire (c'est-à-dire \(E[X_t] = E[X_{t-1}] = \mu\)), nous obtenons :

\[\mu = \phi \mu + 0\] \[\mu(1 - \phi) = 0\]

Si \(\phi \neq 1\) (condition de stationnarité), alors :

\[\mu = E[X_t] = 0 \quad \text{pour} \quad |\phi| < 1\]

Si \(\phi = 1\), le processus est non stationnaire (marche aléatoire) et la moyenne n'est pas définie.

Calcul de la Variance

Pour un processus stationnaire, la variance est constante :

\[\text{Var}(X_t) = \text{Var}(X_{t-1}) = \gamma(0)\]

Calculons la variance de \(X_t\) :

\[\begin{align*} \text{Var}(X_t) &= \text{Var}(\phi X_{t-1} + \varepsilon_t) \\ &= \phi^2 \text{Var}(X_{t-1}) + \text{Var}(\varepsilon_t) + 2\phi \text{Cov}(X_{t-1}, \varepsilon_t) \end{align*}\]

Comme \(\varepsilon_t\) est indépendant de \(X_{t-1}\), \(\text{Cov}(X_{t-1}, \varepsilon_t) = 0\), et :

\[\gamma(0) = \phi^2 \gamma(0) + \sigma^2_{\varepsilon}\]

Résolvons pour \(\gamma(0)\) :

\[\gamma(0)(1 - \phi^2) = \sigma^2_{\varepsilon}\]
\[\gamma(0) = \frac{\sigma^2_{\varepsilon}}{1 - \phi^2} \quad \text{pour} \quad |\phi| < 1\]

Cette variance existe seulement si \(|\phi| < 1\) (condition de stationnarité).

Calcul de l'Autocovariance

L'autocovariance à un décalage \(h\) est définie par :

\[\gamma(h) = \text{Cov}(X_t, X_{t+h})\]

Pour \(h = 1\) :

\[\begin{align*} \gamma(1) &= \text{Cov}(X_t, X_{t+1}) \\ &= \text{Cov}(X_t, \phi X_t + \varepsilon_{t+1}) \\ &= \phi \text{Cov}(X_t, X_t) + \text{Cov}(X_t, \varepsilon_{t+1}) \end{align*}\]

Comme \(\varepsilon_{t+1}\) est indépendant de \(X_t\), \(\text{Cov}(X_t, \varepsilon_{t+1}) = 0\), donc :

\[\gamma(1) = \phi \gamma(0) = \phi \frac{\sigma^2_{\varepsilon}}{1 - \phi^2}\]

Par récurrence, pour tout \(h \geq 1\) :

\[\gamma(h) = \phi^h \gamma(0) = \phi^h \frac{\sigma^2_{\varepsilon}}{1 - \phi^2}\]

De plus, comme l'autocovariance est une fonction paire, pour \(h < 0\) :

\[\gamma(h) = \phi^{|h|} \frac{\sigma^2_{\varepsilon}}{1 - \phi^2} \quad \text{pour} \quad h \in \mathbb{Z}\]

Calcul de l'Autocorrélation (ACF)

L'autocorrélation à un décalage \(h\) est définie par :

\[\rho(h) = \frac{\gamma(h)}{\gamma(0)}\]

En utilisant les résultats précédents :

\[\rho(h) = \frac{\phi^{|h|} \frac{\sigma^2_{\varepsilon}}{1 - \phi^2}}{\frac{\sigma^2_{\varepsilon}}{1 - \phi^2}} = \phi^{|h|}\]
\[\rho(h) = \phi^{|h|} \quad \text{pour} \quad h \in \mathbb{Z}\]

L'ACF d'un processus AR(1) décroît de façon exponentielle à un taux \(|\phi|\).

Calcul de l'Autocorrélation Partielle (PACF)

Pour un processus AR(1), la fonction d'autocorrélation partielle (PACF) prend les valeurs suivantes :

\(\phi_{11} = \rho(1) = \phi\) (pour le décalage 1)

\(\phi_{hh} = 0\) pour \(h > 1\)

\[\phi_{hh} = \begin{cases} \phi & \text{pour } h = 1 \\ 0 & \text{pour } h > 1 \end{cases}\]

Cela signifie que l'autocorrélation partielle est significative uniquement au premier décalage (caractéristique d'un processus AR(1)) et nulle pour tous les autres décalages.

Résumé des propriétés statistiques de l'AR(1)

\[\begin{align*} \text{Moyenne: } & \mu = 0 \\ \text{Variance: } & \gamma(0) = \frac{\sigma^2_{\varepsilon}}{1-\phi^2} \\ \text{Autocovariance: } & \gamma(h) = \phi^{|h|}\frac{\sigma^2_{\varepsilon}}{1-\phi^2} \\ \text{Autocorrélation: } & \rho(h) = \phi^{|h|} \\ \text{Autocorrélation partielle: } & \phi_{hh} = \begin{cases} \phi & \text{pour } h = 1 \\ 0 & \text{pour } h > 1 \end{cases} \end{align*}\]

Toutes ces propriétés sont valables sous la condition de stationnarité \(|\phi| < 1\).
