Processus Autorégressif d'Ordre 2

Analyse détaillée des propriétés statistiques d'un AR(2)

Un processus AR(2) est défini par l'équation : \[X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \varepsilon_t\] où \(\varepsilon_t \sim \text{WN}(0, \sigma^2_{\varepsilon})\) est un bruit blanc de moyenne nulle et de variance \(\sigma^2_{\varepsilon}\).

Conditions de Stationnarité

Un processus AR(2) peut être exprimé sous forme polynomiale avec l'opérateur de retard \(L\) :

\[X_t - \phi_1 X_{t-1} - \phi_2 X_{t-2} = \varepsilon_t\] \[(1 - \phi_1 L - \phi_2 L^2) X_t = \varepsilon_t\]

Pour que le processus soit stationnaire, toutes les racines du polynôme caractéristique \(P(z) = 1 - \phi_1 z - \phi_2 z^2\) doivent être de module strictement supérieur à 1 (ou de manière équivalente, toutes les racines de \(\phi(z) = z^2 - \phi_1 z - \phi_2\) doivent être de module strictement inférieur à 1).

Cela conduit aux conditions suivantes sur les paramètres :

\[\begin{align} \phi_2 + \phi_1 &< 1 \\ \phi_2 - \phi_1 &< 1 \\ |\phi_2| &< 1 \end{align}\]

Ces trois inéquations définissent la région de stationnarité d'un processus AR(2) dans le plan \((\phi_1, \phi_2)\).

Région de stationnarité pour un AR(2)

La région de stationnarité est le triangle à l'intérieur des trois droites. En dehors de cette région, le processus n'est pas stationnaire.

Quand \(\phi_2\) est proche de -1, le processus a tendance à osciller avec une période de deux unités de temps. Quand \(\phi_1 + \phi_2\) est proche de 1, le processus a un comportement similaire à celui d'une marche aléatoire.

Calcul de la Moyenne

Prenons l'espérance de \(X_t\) :

\[E[X_t] = E[\phi_1 X_{t-1} + \phi_2 X_{t-2} + \varepsilon_t] = \phi_1 E[X_{t-1}] + \phi_2 E[X_{t-2}] + E[\varepsilon_t]\]

Comme \(E[\varepsilon_t] = 0\) et en supposant que le processus est stationnaire (c'est-à-dire \(E[X_t] = E[X_{t-1}] = E[X_{t-2}] = \mu\)), nous obtenons :

\[\mu = \phi_1 \mu + \phi_2 \mu + 0\] \[\mu(1 - \phi_1 - \phi_2) = 0\]

Si \(\phi_1 + \phi_2 \neq 1\) (ce qui est assuré par les conditions de stationnarité), alors :

\[\mu = E[X_t] = 0\]

Si le processus inclut une constante \(c\) dans son équation (\(X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \varepsilon_t\)), alors la moyenne ne serait pas nulle et vaudrait :

\[\mu = \frac{c}{1 - \phi_1 - \phi_2}\]

Calcul de la Variance

Pour un processus stationnaire, la variance est constante :

\[\text{Var}(X_t) = \text{Var}(X_{t-1}) = \text{Var}(X_{t-2}) = \gamma(0)\]

Calculons la variance de \(X_t\) :

\[\begin{align*} \text{Var}(X_t) &= \text{Var}(\phi_1 X_{t-1} + \phi_2 X_{t-2} + \varepsilon_t) \\ &= \phi_1^2 \text{Var}(X_{t-1}) + \phi_2^2 \text{Var}(X_{t-2}) + \text{Var}(\varepsilon_t) + 2\phi_1\phi_2\text{Cov}(X_{t-1}, X_{t-2}) \end{align*}\]

Comme \(\text{Cov}(X_{t-1}, X_{t-2}) = \gamma(1)\) et \(\varepsilon_t\) est indépendant de \(X_{t-1}\) et \(X_{t-2}\), nous avons :

\[\gamma(0) = \phi_1^2 \gamma(0) + \phi_2^2 \gamma(0) + \sigma^2_{\varepsilon} + 2\phi_1\phi_2\gamma(1)\]

Pour résoudre cette équation, nous avons besoin d'une expression pour \(\gamma(1)\). On peut l'obtenir par les équations de Yule-Walker (voir l'onglet Autocovariance). Le résultat final pour la variance est :

\[\gamma(0) = \frac{(1-\phi_2)\sigma^2_{\varepsilon}}{(1+\phi_2)(1-\phi_2-\phi_1)(1-\phi_2+\phi_1)}\]

Cette variance existe seulement si les conditions de stationnarité sont remplies.

Calcul de l'Autocovariance

L'autocovariance à un décalage \(h\) est définie par :

\[\gamma(h) = \text{Cov}(X_t, X_{t+h})\]

Pour un AR(2), les autocovariances peuvent être obtenues à partir des équations de Yule-Walker :

Pour \(h = 1\) :

\[\gamma(1) = \phi_1 \gamma(0) + \phi_2 \gamma(-1) = \phi_1 \gamma(0) + \phi_2 \gamma(1)\]

En résolvant pour \(\gamma(1)\) :

\[\gamma(1) = \frac{\phi_1 \gamma(0)}{1 - \phi_2}\]

Pour \(h = 2\) :

\[\gamma(2) = \phi_1 \gamma(1) + \phi_2 \gamma(0)\]

En substituant \(\gamma(1)\) :

\[\gamma(2) = \phi_1 \frac{\phi_1 \gamma(0)}{1 - \phi_2} + \phi_2 \gamma(0) = \gamma(0) \left(\frac{\phi_1^2}{1 - \phi_2} + \phi_2\right)\]

Pour \(h \geq 3\), nous pouvons utiliser la récurrence suivante :

\[\gamma(h) = \phi_1 \gamma(h-1) + \phi_2 \gamma(h-2)\]
\[\gamma(h) = \begin{cases} \frac{(1-\phi_2)\sigma^2_{\varepsilon}}{(1+\phi_2)(1-\phi_2-\phi_1)(1-\phi_2+\phi_1)} & \text{pour } h = 0 \\ \frac{\phi_1 \gamma(0)}{1 - \phi_2} & \text{pour } h = 1 \\ \phi_1 \gamma(h-1) + \phi_2 \gamma(h-2) & \text{pour } h \geq 2 \end{cases}\]

Cette formule de récurrence montre que les autocovariances d'un AR(2) suivent une structure plus complexe que celles d'un AR(1).

Calcul de l'Autocorrélation (ACF)

L'autocorrélation à un décalage \(h\) est définie par :

\[\rho(h) = \frac{\gamma(h)}{\gamma(0)}\]

En utilisant les résultats précédents pour l'autocovariance :

Pour \(h = 1\) :

\[\rho(1) = \frac{\gamma(1)}{\gamma(0)} = \frac{\phi_1}{1 - \phi_2}\]

Pour \(h = 2\) :

\[\rho(2) = \frac{\gamma(2)}{\gamma(0)} = \frac{\phi_1^2}{1 - \phi_2} + \phi_2\]

Pour \(h \geq 3\), les autocorrélations suivent la même récurrence que les autocovariances :

\[\rho(h) = \phi_1 \rho(h-1) + \phi_2 \rho(h-2) \quad \text{pour } h \geq 3\]
\[\rho(h) = \begin{cases} 1 & \text{pour } h = 0 \\ \frac{\phi_1}{1 - \phi_2} & \text{pour } h = 1 \\ \frac{\phi_1^2}{1 - \phi_2} + \phi_2 & \text{pour } h = 2 \\ \phi_1 \rho(h-1) + \phi_2 \rho(h-2) & \text{pour } h \geq 3 \end{cases}\]

L'ACF d'un processus AR(2) peut présenter plusieurs comportements intéressants :

  • Décroissance exponentielle monotone (lorsque les racines sont réelles)
  • Décroissance sinusoïdale amortie (lorsque les racines sont complexes)

Calcul de l'Autocorrélation Partielle (PACF)

Pour un processus AR(2), la fonction d'autocorrélation partielle (PACF) prend les valeurs suivantes :

\(\phi_{11} = \rho(1)\) (pour le décalage 1)

\(\phi_{22} = \phi_2\) (pour le décalage 2)

\(\phi_{hh} = 0\) pour \(h > 2\)

\[\phi_{hh} = \begin{cases} \frac{\phi_1}{1 - \phi_2} & \text{pour } h = 1 \\ \phi_2 & \text{pour } h = 2 \\ 0 & \text{pour } h > 2 \end{cases}\]

Cela signifie que l'autocorrélation partielle est significative seulement aux deux premiers décalages (caractéristique d'un processus AR(2)) et nulle pour tous les autres décalages.

Cette coupure nette de la PACF au décalage p est une caractéristique générale des processus AR(p).

Résumé des propriétés statistiques de l'AR(2)

\[\begin{align*} \text{Moyenne: } & \mu = 0 \\ \text{Variance: } & \gamma(0) = \frac{(1-\phi_2)\sigma^2_{\varepsilon}}{(1+\phi_2)(1-\phi_2-\phi_1)(1-\phi_2+\phi_1)} \\ \text{Autocovariance: } & \gamma(h) = \phi_1 \gamma(h-1) + \phi_2 \gamma(h-2) \quad \text{pour } h \geq 2 \\ \text{Autocorrélation: } & \rho(h) = \phi_1 \rho(h-1) + \phi_2 \rho(h-2) \quad \text{pour } h \geq 3 \\ \text{Autocorrélation partielle: } & \phi_{hh} = \begin{cases} \frac{\phi_1}{1 - \phi_2} & \text{pour } h = 1 \\ \phi_2 & \text{pour } h = 2 \\ 0 & \text{pour } h > 2 \end{cases} \\ \text{Conditions de stationnarité: } & \begin{cases} \phi_2 + \phi_1 < 1 \\ \phi_2 - \phi_1 < 1 \\ |\phi_2| < 1 \end{cases} \end{align*}\]

Toutes ces propriétés sont valables sous les conditions de stationnarité.
