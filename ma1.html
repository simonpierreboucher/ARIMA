Processus à Moyenne Mobile d'Ordre 1

Analyse détaillée des propriétés statistiques d'un MA(1)

Un processus MA(1) est défini par l'équation : \[X_t = \varepsilon_t + \theta \varepsilon_{t-1}\] où \(\varepsilon_t \sim \text{WN}(0, \sigma^2_{\varepsilon})\) est un bruit blanc de moyenne nulle et de variance \(\sigma^2_{\varepsilon}\).

Calcul de la Moyenne

Prenons l'espérance de \(X_t\) :

\[E[X_t] = E[\varepsilon_t + \theta \varepsilon_{t-1}] = E[\varepsilon_t] + \theta E[\varepsilon_{t-1}]\]

Comme \(E[\varepsilon_t] = E[\varepsilon_{t-1}] = 0\) (propriété du bruit blanc), nous obtenons :

\[E[X_t] = 0 + \theta \cdot 0 = 0\]
\[\mu = E[X_t] = 0\]

Contrairement au processus AR(1), la moyenne d'un processus MA(1) est toujours égale à 0, quelle que soit la valeur de \(\theta\).

Calcul de la Variance

La variance de \(X_t\) est donnée par :

\[\text{Var}(X_t) = \text{Var}(\varepsilon_t + \theta \varepsilon_{t-1})\]

Comme \(\varepsilon_t\) et \(\varepsilon_{t-1}\) sont indépendants (propriété du bruit blanc), nous avons :

\[\begin{align*} \text{Var}(X_t) &= \text{Var}(\varepsilon_t) + \text{Var}(\theta \varepsilon_{t-1}) + 2\text{Cov}(\varepsilon_t, \theta \varepsilon_{t-1}) \\ &= \sigma^2_{\varepsilon} + \theta^2 \sigma^2_{\varepsilon} + 2\theta \cdot 0 \\ &= \sigma^2_{\varepsilon}(1 + \theta^2) \end{align*}\]
\[\gamma(0) = \text{Var}(X_t) = \sigma^2_{\varepsilon}(1 + \theta^2)\]

La variance d'un processus MA(1) est toujours finie et ne dépend que de \(\theta\) et de la variance du bruit \(\sigma^2_{\varepsilon}\).

Remarque importante : Un processus MA(1) est toujours stationnaire quelle que soit la valeur de \(\theta\), contrairement au processus AR(1) qui exige \(|\phi| < 1\) pour être stationnaire.

Calcul de l'Autocovariance

L'autocovariance à un décalage \(h\) est définie par :

\[\gamma(h) = \text{Cov}(X_t, X_{t+h})\]

Pour \(h = 1\) :

\[\begin{align*} \gamma(1) &= \text{Cov}(X_t, X_{t+1}) \\ &= \text{Cov}(\varepsilon_t + \theta \varepsilon_{t-1}, \varepsilon_{t+1} + \theta \varepsilon_t) \\ \end{align*}\]

Développons cette covariance :

\[\begin{align*} \gamma(1) &= \text{Cov}(\varepsilon_t, \varepsilon_{t+1}) + \text{Cov}(\varepsilon_t, \theta\varepsilon_t) + \text{Cov}(\theta\varepsilon_{t-1}, \varepsilon_{t+1}) + \text{Cov}(\theta\varepsilon_{t-1}, \theta\varepsilon_t) \\ &= 0 + \theta\text{Var}(\varepsilon_t) + 0 + 0 \\ &= \theta\sigma^2_{\varepsilon} \end{align*}\]

Pour \(h = 2\) :

\[\begin{align*} \gamma(2) &= \text{Cov}(X_t, X_{t+2}) \\ &= \text{Cov}(\varepsilon_t + \theta \varepsilon_{t-1}, \varepsilon_{t+2} + \theta \varepsilon_{t+1}) \end{align*}\]

Développons cette covariance :

\[\begin{align*} \gamma(2) &= \text{Cov}(\varepsilon_t, \varepsilon_{t+2}) + \text{Cov}(\varepsilon_t, \theta\varepsilon_{t+1}) + \text{Cov}(\theta\varepsilon_{t-1}, \varepsilon_{t+2}) + \text{Cov}(\theta\varepsilon_{t-1}, \theta\varepsilon_{t+1}) \\ &= 0 + 0 + 0 + 0 \\ &= 0 \end{align*}\]

Ainsi, pour tout \(h > 1\), \(\gamma(h) = 0\).

\[\gamma(h) = \begin{cases} \sigma^2_{\varepsilon}(1 + \theta^2) & \text{pour } h = 0 \\ \theta\sigma^2_{\varepsilon} & \text{pour } |h| = 1 \\ 0 & \text{pour } |h| > 1 \end{cases}\]

Cette propriété est très importante : l'autocovariance d'un processus MA(1) est nulle au-delà du décalage 1. Cela signifie que les observations séparées de plus d'une période ne sont pas linéairement corrélées.

Calcul de l'Autocorrélation (ACF)

L'autocorrélation à un décalage \(h\) est définie par :

\[\rho(h) = \frac{\gamma(h)}{\gamma(0)}\]

En utilisant les résultats précédents :

\[\rho(1) = \frac{\gamma(1)}{\gamma(0)} = \frac{\theta\sigma^2_{\varepsilon}}{\sigma^2_{\varepsilon}(1 + \theta^2)} = \frac{\theta}{1 + \theta^2}\]
\[\rho(h) = 0 \quad \text{pour } |h| > 1\]
\[\rho(h) = \begin{cases} 1 & \text{pour } h = 0 \\ \frac{\theta}{1 + \theta^2} & \text{pour } |h| = 1 \\ 0 & \text{pour } |h| > 1 \end{cases}\]

L'ACF d'un processus MA(1) a une "coupure" après le décalage 1. C'est une caractéristique distinctive des processus à moyenne mobile : pour un MA(q), l'ACF est nulle après le décalage q.

Remarque : \(|\rho(1)| \leq 0.5\) pour tout \(\theta\), avec \(\rho(1) = 0.5\) quand \(\theta = 1\) et \(\rho(1) = -0.5\) quand \(\theta = -1\).

Calcul de l'Autocorrélation Partielle (PACF)

Pour un processus MA(1), la fonction d'autocorrélation partielle (PACF) est plus complexe que pour l'AR(1) et décroît de façon exponentielle.

Nous pouvons calculer les premiers termes à partir des équations de Yule-Walker :

\[\phi_{11} = \rho(1) = \frac{\theta}{1 + \theta^2}\]

Pour \(h \geq 2\), la PACF suit une décroissance exponentielle qui dépend de la valeur de \(\theta\) :

\[\phi_{hh} = \begin{cases} \frac{\theta}{1 + \theta^2} & \text{pour } h = 1 \\ \frac{\theta^h - \theta^{h-2}}{1 + \theta^2} & \text{pour } h \geq 2 \end{cases}\]
\[\phi_{hh} \approx \begin{cases} \frac{\theta}{1 + \theta^2} & \text{pour } h = 1 \\ (-\theta)^{h-1}\frac{\theta^2}{1+\theta^2} & \text{pour } h \geq 2 \text{ et } |\theta| < 1 \end{cases}\]

Contrairement à l'ACF qui a une coupure après le décalage 1, la PACF du MA(1) a une décroissance progressive, qui peut être approximée par une exponentielle pour \(|\theta| < 1\).

Condition d'Inversibilité

Un processus MA(1) peut être réécrit comme un processus AR(∞) sous certaines conditions :

\[X_t = \varepsilon_t + \theta \varepsilon_{t-1} = \varepsilon_t + \theta L \varepsilon_t\] \[X_t = (1 + \theta L) \varepsilon_t\]

Pour exprimer \(\varepsilon_t\) en fonction des \(X_t\), nous avons besoin de l'inverse de l'opérateur \((1 + \theta L)\) :

\[\varepsilon_t = \frac{1}{1 + \theta L} X_t\]

Si \(|\theta| < 1\), nous pouvons développer cette fraction en série :

\[\frac{1}{1 + \theta L} = \sum_{j=0}^{\infty} (-\theta L)^j\] \[\varepsilon_t = \sum_{j=0}^{\infty} (-\theta)^j X_{t-j}\]

Par conséquent, le processus MA(1) peut être réécrit comme un processus AR(∞) lorsque \(|\theta| < 1\). Cette condition est appelée "condition d'inversibilité".

\[\text{Condition d'inversibilité : } |\theta| < 1\]

L'inversibilité est importante pour la prévision et l'estimation des paramètres. Un MA(1) inversible a une représentation AR unique, ce qui facilite l'inférence statistique.

Remarque : Tous les processus MA(q) sont stationnaires, mais pour qu'ils soient inversibles, les racines du polynôme caractéristique doivent être de module strictement supérieur à 1.

Résumé des propriétés statistiques du MA(1)

\[\begin{align*} \text{Moyenne: } & \mu = 0 \\ \text{Variance: } & \gamma(0) = \sigma^2_{\varepsilon}(1 + \theta^2) \\ \text{Autocovariance: } & \gamma(h) = \begin{cases} \sigma^2_{\varepsilon}(1 + \theta^2) & \text{pour } h = 0 \\ \theta\sigma^2_{\varepsilon} & \text{pour } |h| = 1 \\ 0 & \text{pour } |h| > 1 \end{cases} \\ \text{Autocorrélation: } & \rho(h) = \begin{cases} 1 & \text{pour } h = 0 \\ \frac{\theta}{1 + \theta^2} & \text{pour } |h| = 1 \\ 0 & \text{pour } |h| > 1 \end{cases} \\ \text{Condition d'inversibilité: } & |\theta| < 1 \end{align*}\]

Un processus MA(1) est toujours stationnaire, quelle que soit la valeur de \(\theta\).
