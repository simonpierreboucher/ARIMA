Preuve de la moyenne d'un processus AR(1)

Définition du processus AR(1)

Un processus autorégressif d'ordre 1, noté AR(1), est défini par l'équation récursive suivante :

X_t = c + \phi X_{t-1} + \varepsilon_t

où :

  • \( X_t \) est la valeur du processus au temps t
  • \( c \) est une constante
  • \( \phi \) est le paramètre autorégressif (avec \( |\phi| < 1 \) pour assurer la stationnarité)
  • \( \varepsilon_t \) est un bruit blanc de moyenne nulle et de variance \( \sigma^2_\varepsilon \)

Théorème

Si un processus AR(1) est stationnaire et que \( |\phi| < 1 \), alors la moyenne du processus, notée \( \mu = E[X_t] \), est donnée par :

\mu = \frac{c}{1-\phi}

Preuve

Nous cherchons la moyenne d'un processus AR(1) stationnaire. La stationnarité implique que la moyenne est constante dans le temps, c'est-à-dire \( E[X_t] = E[X_{t-1}] = \mu \) pour tout t.

Commençons par l'équation du processus AR(1) :

X_t = c + \phi X_{t-1} + \varepsilon_t

Prenons l'espérance mathématique des deux côtés de cette équation :

E[X_t] = E[c + \phi X_{t-1} + \varepsilon_t]

Par linéarité de l'espérance :

E[X_t] = E[c] + E[\phi X_{t-1}] + E[\varepsilon_t]

Comme \( c \) est une constante, \( E[c] = c \). De plus, \( \phi \) est également une constante, donc \( E[\phi X_{t-1}] = \phi E[X_{t-1}] \). Par hypothèse, \( \varepsilon_t \) est un bruit blanc de moyenne nulle, donc \( E[\varepsilon_t] = 0 \). Ainsi :

E[X_t] = c + \phi E[X_{t-1}] + 0
E[X_t] = c + \phi E[X_{t-1}]

Comme nous avons supposé que le processus est stationnaire, \( E[X_t] = E[X_{t-1}] = \mu \) pour tout t. En substituant :

\mu = c + \phi \mu

Résolvons cette équation pour \( \mu \) :

\mu - \phi \mu = c
\mu(1 - \phi) = c
\mu = \frac{c}{1-\phi}

Cette formule est valide uniquement lorsque \( |\phi| < 1 \), ce qui est précisément la condition de stationnarité pour un processus AR(1).

∎

Remarques importantes

  • La condition \( |\phi| < 1 \) est cruciale pour la stationnarité du processus AR(1). Si \( |\phi| \geq 1 \), le processus n'est pas stationnaire et la formule ci-dessus n'est pas applicable.
  • Lorsque \( \phi = 0 \), le processus AR(1) se réduit à un bruit blanc avec dérive, et la moyenne devient simplement \( \mu = c \).
  • Lorsque \( c = 0 \), la moyenne du processus est \( \mu = 0 \), ce qui correspond à un processus AR(1) centré.
  • Plus \( \phi \) est proche de 1, plus la moyenne \( \mu \) est amplifiée par rapport à la constante \( c \).
